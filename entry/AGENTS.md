开始任何任务前，先读我的个人档案索引：`<档案路径>/MEMORY.md`，
再按当前任务打开其中相关的文件。读法与写回规矩见同目录 `README.md`。

- `feedback_` 开头的文件是我的做事要求，优先遵守。
- 学到新的偏好、踩到新的坑，写回档案：一个文件一件事，并在 `MEMORY.md` 加一行索引。
- 档案是 git 仓库，改完在档案目录执行 `git add -A && git commit -m "说明改了什么"`。
- 档案含个人信息，不得外传，不得写入密码和密钥。
